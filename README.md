A high-performance, transparent web-based overlay designed for gamers. Whether you need a competitive crosshair, visual indicators for navigation, or help with directional orientation, AxiSight provides a zero-lag, click-through solution.

🚀 QUICKSTART: How to run locally (NO HOSTING NEEDED)

You don't need to be a coder or host this online. I have baked everything into a single file for you.

1. **Get the File:** Download this project as a ZIP (Settings -> Export as ZIP).
2. **Find the HTML:** Locate `AxiSight-Overlay.html` in the root folder.
3. **Run:** Double-click `AxiSight-Overlay.html`. It opens in your default browser.
4. **Go Fullscreen:** Inside the app menu, hit the **FULLSCREEN** button to hide your address bar and tabs.
5. **Overlay Setup:** 
   - Since browsers don't natively "float" over games, check the **Help Modal (?)** inside the app. 
   - **THE BEST METHOD (Steam Users):** Launch your game, hit **Shift+Tab**, open the Steam Browser, paste the URL of this app.
   - **CRITICAL:** Click the **PIN** icon at the top right of the Steam browser window. This is mandatory for the overlay to stay visible during gameplay.
   - **⚠️ WARNING:** Be careful with Steam's global overlay opacity settings. If the global overlay opacity is high, the "pinned" window might become visible or obscure your view. Keep the window pinned and use the window-specific opacity slider for the cleanest look.
   - It also contains specific solutions for **microSLOP binbows**, **Linux**, and **macOS** using Xbox Game Bar, WindowTop, or Plasma/Wayland hacks.



 🧠 What is this?

AxiSight is a hardware-agnostic "Virtual HUD". It allows you to project custom text and generative crosshairs onto your screen. It is built using "vibe coding" logic to ensure it remains lightweight, fast, and compatible across all operating systems.

Features:
- **Generative Crosshair Builder:** Create your own SVG crosshair with sliders for thickness, length, gap, and circles.
- **Custom Image Support:** Drop in your own `.png` or `.svg` files.
- **Dynamic Indicators:** High-contrast text overlays to help with screen positioning.
- **Config Persistence:** Save your setup to a `.json` file and load it back instantly.
- **Hotkeys:** Toggle the menu with `INSERT` or `HOME`.



 🧭 About LRC and LRD

This program was specifically designed with features to assist users dealing with **LRC (Left-Right Confusion)** and **LRD (Left-Right Difficulty/Disorder)**.

For many people, distinguishing between "Left" and "Right" in high-pressure situations (like gaming) isn't instantaneous. AxiSight provides:
- **Static Visual Anchors:** Permanent "LEFT" and "RIGHT" indicators on the screen to remove the mental load of directional processing.
- **Custom Spanning:** Adjustable horizontal spread to place the labels exactly where your peripheral vision can catch them.
- **Focus Aids:** Helps users with pareidolia or spatial orientation issues stay centered on their target.



 🛠️ Installation & Setup

 Offline Usage (Recommended)
Simply keep `AxiSight-Overlay.html` on your desktop or in your main gaming folder. You can even add it to Steam as a "Non-Steam Game" and launch it directly from your library!

 Configuration
Your settings (colors, sizes, positions) are saved automatically to your browser's local storage. If you want to move your setup to a different PC, use the **Save JSON** button and **Load JSON** on the new instance.
